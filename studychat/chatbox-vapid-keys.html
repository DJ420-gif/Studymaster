🔑 Push keys generator

Real notifications (even when the browser is closed) need one pair of keys. They are created here, inside your own browser — nothing is sent anywhere.

1. PUBLIC key

Safe to share. Paste it into chatbox-notify.js (vapidPublicKey) and into the Worker CONFIG (vapidPublicKey).

2. PRIVATE key

Keep it secret. Paste it ONLY into the Worker CONFIG (vapidPrivateJwk). Never put it in the chat website.
